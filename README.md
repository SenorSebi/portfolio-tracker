# Portfolio Tracker

Personal investment portfolio tracker with live prices from Yahoo Finance.

## Setup

```bash
npm run install:all
```

## Development

```bash
npm run dev
```

Frontend runs on http://localhost:3000  
Backend API runs on http://localhost:3001

## Features
- Multi-sector portfolio tracking (AI Infrastructure, Industrial/Energy, Biotech, Free segment)
- Live prices via Yahoo Finance (5-minute cache)
- EUR/USD conversion
- DCA zone tracking with status badges
- Trade logging with CSV export
- SQLite database for persistence
